# Computational Optimisation Notebooks

This repo contains a small set of Marimo notebooks that visualize functions used in computational optimisation discussions.

## Notebooks

- `notebook1.py`: 3D surface for f(x1, x2) = (x2 - x1^2)(x2 - 2 x1^2) with sliders for domain and grid resolution.
- `notebook2.py`: 2D plot of h(x)=e^x, g(x)=-sqrt(x), and f(x)=g(h(x)) with adjustable range and sampling.
- `notebook3.py`: 3D surface for f(x1, x2) = x1^2 - x2^2 (saddle surface) with sliders for domain and grid resolution.

## Run

Use Marimo to run a notebook:

```sh
uvx marimo run notebook1.py
```

Replace `notebook1.py` with the notebook you want to view.
